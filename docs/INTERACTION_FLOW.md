# 雁过有声｜点击操作逻辑 v1

本版本只定义页面关系和点击行为。页面中的标题、故事、标签与提示语均作为占位文案，后续统一替换。

## 1. 两条主路径

```text
浏览别人的故事
故事瀑布流 → 故事详情 → 讲述者花海 → 点击一朵花 → 对应故事详情

生成自己的故事
讲述入口 → 主题选择 → 语音访谈 → 价值显影 → 结果确认
                                         ├→ 生成分享卡 → 保存 / 分享 / 加入花海
                                         └→ 直接加入我的花海
```

## 2. 底部导航

| 入口 | 点击结果 | 规则 |
| --- | --- | --- |
| 故事 | 进入故事瀑布流 | 作为默认首页 |
| 讲述 | 进入讲述主题选择 | 始终从一件小事开始新的访谈 |
| 我的花海 | 进入个人花海 | 展示本人已经确认加入的故事 |

底部导航只出现在故事流和本人花海等一级页面。访谈、详情、结果与分享卡使用页面内返回，避免用户误触离开当前任务。

## 3. 页面点击表

| 页面 | 可点击对象 | 去向或反馈 |
| --- | --- | --- |
| 故事瀑布流 | 故事卡 | 对应故事详情 |
| 故事瀑布流 | 头像 / 姓名 | 对应讲述者花海 |
| 故事详情 | 头像 / 姓名 | 对应讲述者花海 |
| 故事详情 | 原声 | 播放 / 暂停原声 |
| 个人花海 | 木兰花 | 对应故事详情 |
| 主题选择 | 返回 | 回到进入前的一级页面 |
| 主题选择 | 开始语音对话 | 进入第一轮访谈 |
| 语音访谈 | 重听 | AI 重新朗读当前问题 |
| 语音访谈 | 点一下讲述 | 开始收音；再次点击结束本轮 |
| 语音访谈 | 暂时没什么想说 | 结束访谈并开始价值显影 |
| 价值结果 | 修改 | 回到访谈继续补充 |
| 价值结果 | 分享图标 / 生成分享卡 | 进入分享卡预览 |
| 价值结果 | 加入我的花海 | 写入本人花海后进入个人页 |
| 分享卡 | 保存图片 | 在本地生成并下载 PNG |
| 分享卡 | 分享给朋友 | 调用系统分享；不支持时改为下载 |
| 分享卡 | 加入我的花海 | 写入本人花海后进入个人页 |

## 4. 返回与历史记录

- 从哪里进入详情，就返回哪里；例如从阿琴的花海打开故事，返回仍是阿琴的花海。
- 讲述主题页返回进入前的故事流或个人花海。
- 访谈第一轮返回主题选择；后续轮次返回上一轮问题。
- 手机浏览器的系统后退键与页面内返回按钮保持一致。
- 当前页面写入 URL hash，便于刷新、演示和定位页面，但不引入第三方路由库。

## 5. 权限与公开边界

- 访谈结果默认只在当前设备中展示。
- 只有点击“加入我的花海”后，故事才进入本人花海。
- 只有点击“分享给朋友”或保存图片后，内容才离开当前页面。
- 浏览区域不提供点赞、排行、关注与评论入口。
