# 木兰

> 让她看见自己，也让世界看见她。

一款发现和展示流动女工真实生活和智慧的AI产品。

## 当前原型

- 移动端优先的响应式 Web
- AI 语音提问与动态追问
- 用户单击开始、再次单击结束语音讲述
- 基于故事证据的价值结果页
- 可保存与分享的个人故事卡
- 每个帖子使用从产品视觉稿中裁出的不同木兰花配图
- 无点赞、排行与关注压力的故事瀑布流
- 可点击每朵木兰进入故事的个人花海
- 经本人主动确认后，故事才加入花海或对外分享

## 本地运行

在仓库根目录执行：

```powershell
python -m http.server 4173 --directory mulan-value-demo
```

然后打开 <http://127.0.0.1:4173/>。

首次使用语音功能时，需要允许浏览器访问麦克风。语音识别与朗读能力取决于浏览器对 Web Speech API 的支持。

## 项目结构

- `mulan-value-demo/`：可交互 HTML 原型
- `design/`：产品视觉稿
- `PROJECT_CONTEXT.md`：项目长期上下文
- `docs/PRD_BASELINE.md`：当前产品与验收基线
- `docs/INTERACTION_FLOW.md`：页面路由、点击行为与返回规则
- `docs/source/`：原始需求文档附件

## 产品原则

真实证据、原声优先、本人认领、尊严而非怜悯。AI 只提出有故事证据支持的价值候选，不替用户进行人格判断。
